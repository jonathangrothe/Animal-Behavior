# Neural Field Exploration

This repository holds the code I used to explore the neural field model for animal behavior proposed in Allocentric Flocking. An in depth report of the work I have done from March 2026-September 2026 is detailed in the Neural Field Write Up file. 

## Organization

The matlab_scripts folder contains the original files I was given from allocentric flocking, I added a few comments but besides that used these to rewrite the ring attractor model in Python. 

The python_scripts folder contains the code I used to perform my analysis.

The helper_functions folder contains a few functions I used to produce figures for the report and a few functions that were too long for the respective python_scripts files. 

The tests folder is mostly useless as it was intended as a way to push some of the metrics I used to evaluate the metrics I used, but it made me realize that those metrics were not the best way to go about my analysis. 

The plots folder contains a variety of plots I have produced along the way. In the examples folder there is a folder called report figures which contains all the figures and videos mentioned in the report. The videos are also available on YouTube on the channel [Neural Field Videos](https://www.youtube.com/@NeuralFieldVideos). The three target bilateral symmetry folder shows all the plots I produced in my structured analysis of the three target case.
